# Allowlist for scripts/export-public.sh — this file is public and is exported with the code.
#
# The export fails closed: every file in the exported tree must match one of the path globs below
# AND have an extension from the ext: list (or be a noext: name). Anything else is reported and the
# export fails. Add a line here only after checking that the new kind of file is safe to publish.
#
# Format (one entry per line; blank lines and lines starting with # are ignored):
#   <glob>              path relative to the repository root; ** = any depth, * and ? stay inside one
#                       directory level; matching is case-sensitive
#   ext:<extension>     allowed file extension (the part after the last dot of the file name)
#   noext:<name>        allowed file name without an extension
#   binary:<path>       exact path of a file that may be binary (no other file may be)
#   exclude:<glob>      never published, even inside an allowed glob (exclusions win)
#   exact-line:<path>|<categories>|<line>
#                       the exact full line (no trailing spaces) in <path> that may contain the owner's
#                       name and/or a facebook.com link; <categories> is name, facebook or both. Every
#                       other rule still applies to that line, and nowhere else is exempt.
#   invisible:<path> U+XXXX   that invisible character may appear in that file (e.g. a BOM literal)
#   password-value:<value>    a fake password (or fake secret/token) used by tests or docs; matched
#                       exactly, also for the long hex/base64 secret rule
#   ip-value:<value>    a dotted number that is not an address (e.g. a version)
#   env-value:<value>   allowed value in .env.example (besides empty, small integers, true/false/null
#                       and ${OTHER_KEY} references); applies to commented-out KEY= lines and to
#                       KEY=value written inside comment text too
#
# exact-line: and password-value: entries exempt text from the checks, so each one is recorded in
# public-allowlist.lock (first 12 hex digits of the sha256 of the entry line). The export fails while
# the two disagree: review every changed entry by hand, then run
# scripts/export-public.sh --update-allowlist-lock and commit both files together.
